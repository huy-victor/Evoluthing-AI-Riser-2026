# AIRiser Vietnam 2026 — Competition Context

Essential facts about the competition this project is an entry for. Use this
as background context when building Evoluthing.

## What it is
**#AIRiser Vietnam 2026** (#BuildwithGoogleAI) — Google's innovation jam for
anyone to build an AI-powered solution via vibe coding. No coding experience
required. Participation is free and open to anyone based in Vietnam.

- Official page: https://rsvp.withgoogle.com/events/airiservietnam
- Registration / leaderboard: https://goo.gle/airiservietnam
- Community: Slack at https://slack.airiservietnam.dev/

## Timeline
- Start: Aug 1, 2026
- **Deadline to submit Completion Form: Aug 30, 2026**
- Winners announced via email

## Build stack (required)
- **Google AI Studio** (Gemini) to build the app
- Deploy to **Google Cloud Run** (web) or **Google Play** (mobile)
- Optional Google tech for bonus points: Gemini, Firebase, Maps, Workspace
  (Gmail, Calendar, Sheets), etc.

## Submission requirements (Bronze tier, mandatory for ranking)
1. **App Link** — a public Google AI Studio share link
2. **Demo Video** — public YouTube video, max 2 minutes (user flow + features)
3. **LinkedIn Post** — public post sharing the project, hashtags
   #AIRiserVietnam #BuildwithGoogleAI
4. Optional: live Google Cloud Run / Google Play link

## Scoring
- **Idea Evaluation: up to 100 pts** (creativity, feasibility, impact)
- **Google Tech Integration: +10 pts** (depth + proper use of Google tech)
- **Deployment: +10 pts** (live public link; web = Cloud Run only, mobile =
  Google Play only)
- Only submissions via the Completion Form are eligible for leaderboard prizes
- Swag ships to Vietnamese addresses only

## Tiers
- **Bronze**: open to all (submit the Completion Form) → digital certification
- **Silver**: top 500 leaderboard → certification + swag
- **Gold**: top 50, ranked by most impactful solutions → certification + swag
  + mentorship. Applications with **active user engagement** (data/insights/
  stories as proof, submitted in the form) have a significant advantage.
- **Platinum**: top 10 → certification + swag + mentorship + showcase

## Theme
Evoluthing competes in the **Education** category. Theme is selected at
submission time, not at registration.

## Tips from organizers
- Publish / deploy within AI Studio (Cloud Run or Play)
- Collect user-engagement evidence from day one (Gold-tier advantage)
